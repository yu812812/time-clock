# 自欺欺人时钟

把时间改成你想看到的样子 —— 包括把 `19:40` 显示成 `18:100`。

**打开即用：** https://yu812812.github.io/time-clock/

单文件网页，纯前端：没有依赖、没有构建、不联网、不收集任何数据。

## 两套进位引擎

| 引擎 | 19:40 显示为 | 说明 |
|---|---|---|
| **乙 · 逐位借位** | `18:100` | 把「1 小时 = 60 分钟」借成「1 小时 = 100 分钟」的读法 |
| **甲 · 规范进位** | `11:800` | 真实分钟按「每 100 记 1」规范化 |

两套都满足：**不重不漏、单调不回头、显示永不晚于真实时间**。

## 我爱你模式

时间锚点里选「**我爱你**」，页面就不再看钟点，而是盯着**每天 5:20**：

```
              07:53 ♥
    上一次 5:20 已过 16 小时 6 分 · 下一次 5:20 还剩 7 小时 53 分
```

- 主显示是**像 24 小时制钟点一样的 `HH:MM`**，表示距离最近的 5:20 还有（或已过）多久
- 中间用粉色 `♥` 代替冒号，一眼看出不是普通钟表
- 下方同时给出**上一次已过多久**和**下一次还剩多久**（两者相加恒为 24 小时）
- 一天有两个 5:20（凌晨和下午），取离现在最近的那个
- 数字跟随「记数文字」设置：选中文就是 `〇七 ♥ 五三`，选文言就是 `〇柒 ♥ 伍參`

## 背景：凹面鱼眼滚动文字

背景有一层文字**从右往左**滚动，排版是**随机**的 ——
每条的字号、纵向位置和速度都不一样，看起来像随手撒上去的，但方向始终一致。

- **字号随机**：0.52× ～ 1.30×，不会离谱到看不清
- **位置随机**：每条落在不同的纵向高度
- **速度随机**：每条快慢略有差别（0.55× ～ 1.35×），整体仍是一起向左
- 所有行**共用一个滚动量**，不会各行错位
- **设置 → 背景文字** 里直接编辑，一行一句；只写一行会自动重复铺满
- **滚动速度** 0 = 静止
- **支持 emoji**（🐳 ⏰ ❤️ 🎉 …）

实现是纯 2D 画布（`canvas.getContext('2d')`）：每帧把每条文字横向重复画满整行，
左侧出去的部分自然从右侧接回来。逐条的随机样式只算一次并缓存，所以不吃性能。

### 每个时间锚点自带默认语句

点不同的时间锚点，背景会自动换成该锚点对应的句子：

| 锚点 | 背景默认语句 |
|---|---|
| 真实现在 | 🙈 真实时间是什么 · 我只看我想看的 · 假的更好 🫣 |
| 时间膨胀 | ⏳ 时间还早 · 单位都换了，那就不算晚 · 一天有 36 小时 🐳 |
| 我爱你 | 还在等时间的爱意💖 |
| 本小时整点 | 🕐 才刚过整点 · 整点刚敲过 · 现在动手都不算迟 🍃 |
| 就低不就高 | 🧮 抹个零 · 误差不算数 · 四舍五入就是没超时 📉 |
| 永远昨天 | 📅 日期往回一拨，今天就是昨天 · 昨天的债不算今天的债 🌙 |
| 永远新年 | 🎉 只要我愿意，今天永远是新年的第一天 · 一切从头开始 ✨ |

一旦你**手动改过文字**，模式就切到「自定义」，不再被锚点覆盖；
想恢复跟随就点「默认语句 → 跟随锚点」。
「↺ 回到真实」只重置时间相关设置，不会清掉你写的背景文字。

### 「回到真实」的彩蛋

点右上角 **↺ 回到真实** 时，背景会换成这句话：

```
你回到了现实，不再自欺欺人，这是不是也是一种自欺欺人🤔
```

状态标签同时会显示「与真实时间一致 —— 这也算一种自欺欺人」。
这句话会覆盖你当前的背景文字并记为「自定义」，刷新后仍在；
想换回锚点自带的语句，点「背景文字 → 默认语句 → 跟随锚点」。

## 事件提醒 · 倒计时

**设置 → 事件提醒** 里添加任何「有时间、有事、有地点」的安排 —— 课、会、取快递都行。
倒计时把它们统一处理：主显示就是距下一件事还剩多少。

### 两种重复方式

| 方式 | 用途 |
|---|---|
| **就一次** | 指定日期的一件事，如「9 月 16 日 15:00 取快递」 |
| **每周重复** | 选了星期几就每周循环，如「每周一/三 08:00 高等数学」；可设「从哪天开始」 |

列表按**下一次发生**排序，每条显示时间、星期、事由、地点和剩余时间。
点任意一条可以修改，右侧 ✕ 删除。

### 倒计时规则

| 剩余 | 主显示 | 为什么这样 |
|---|---|---|
| > 2 小时 | `4:00`（时:分） | 正常 |
| ≤ 2 小时 | `120`（分钟） | 数字开始变大 |
| **≤ 1 小时** | **`3600`（秒）** | **1 小时变成 3600，看着特别经用** |
| 正在进行 | `4200 秒后结束` | 结束也给你一个很大的数字 |

### 一整套障眼法（设置 → 倒计时障眼法）

- **偷加时间**：倒计时里偷偷多显示一点（默认最多 +30%），而且每秒微抖 ——
  看着时间一直在"多出来"
- **假的提前量**：把事件开始时间往后挪（默认 5 分钟），于是你以为还早
- **藏起时间**：不显示具体几点到几点，眼不见心不烦
- **关掉提醒**：不再出现「快到了」这类字样
- **模糊背景**：背景和文字虚化，专心盯着那个大数字

### 跳过某些天

**设置 → 跳过某些天** 里标记某个日期「放假（跳过）」，
倒计时会直接跳到下一次安排 —— 假期里就不用看着每周重复的课了。

### 数据存在哪

事件存在浏览器本地（`localStorage`），**不上传、别人看不到**。
换设备或清缓存会丢。

## 自我评价 · 让今天看起来更努力

### 专注鱼缸

**在页面上待着就长鱼** —— 什么都不用做。每 20 分钟一条，最多 24 条，
凑够 3 / 6 / 12 条分别给「有点东西 / 今日高产 / 摸鱼冠军」称号。
本质是奖励你盯着钟看：什么都没干，但你有鱼了。

### 走神不算数

它替你自动抹账：

- **切走标签页 / 最小化**，回来时那段时间从「今日已过」里凭空消失
- **静置超过 45 秒**（阈值可调 10–180 秒）也算走神
- 开关可关；关掉后所有空档都如实计入

于是你刷了两小时手机，回来一看「今日已过」只有 1 小时 20 分。

### 账本与标签

页面底部会显示一行小字：

```
今日 4 小时 12 分 · 没算 1 小时 38 分 · 自欺 47 次
```

最损的地方在这：它**用数字告诉你被骗了多少**，但你看着反而挺爽。
设置 → 走神不算数 里能看到完整明细（真的待了多久、被抹掉多久），也可以一键清零。

数据按天存在浏览器本地，只留最近 40 天，**不上传**。

## 幻觉装饰 · 让今天看起来像在努力

### 假连续打卡

「已连续 <b>127</b> 天」，可手动 +1，**中间漏掉的几天会自动补签** ——
连续天数永远不断，你不会看到自己断过。

### 毅力进度条

永远 87%。可以「再撑一点」，但**最多只到 98%** ——
满了就没有努力的空间了。

### 假完成度

一键给所有事件挂上 50% / 75% / 90% / 99%，事件列表右侧会显示这个数字。

### 心想事成话术

开启后，页面上那些安慰话会先过一遍替换 —— 难听的说法自动变成好听的：

```
还有时间，属于误差，慢慢来
        ↓
时间还很充裕，属于合理区间，按自己的节奏走
```

规则可以自己改（每行一条，用 `→` 分隔）。

### 假装很忙

页脚会滚动显示一串假状态，**进度永远不到 100%**：

```
⚙ 正在同步数据… 47%   →   ⚙ 正在校验接口… 62%   →   …
```

状态文案可以自己改。

## 页面小玩意（在主显示下方，不在设置里）

主显示下面有一排小挂件，点一下就用，不用翻设置。
点最左边的 **🧰 收起** 可以把整排收起来。

| 挂件 | 干什么 |
|---|---|
| **❄ 时间冻结** | 钟面定住不动（真的不动），底部真实时间照走 |
| **➕ 还早 5 分钟** | 每点一次把显示往后推 5 分钟，纯安慰剂；可一键取消 |
| **⏱ 今日** | 显示今天在页面上待了多久（点一下看被抹掉多少） |
| **📜 宜 …** | 每日黄历，宜拖延 / 忌打开待办 |
| **🔔 假装有正事** | 弹出假的成就通知（「已连续专注 47 分钟 ✓」） |
| **📺 花屏一下** | 钟面炸一下乱码，0.42 秒后自己恢复 |
| **⬆ 假装在更新** | 全屏「系统正在更新」遮罩，进度永远到不了 100% |
| **🌤 今日宜** | 假天气预报 + 黄历注解 |

## 其它可以调的

- **时段制**：24 小时制 / 12 小时制
- **记数文字**：阿拉伯数字 / 中文小写 / 纯文言（十二时辰 + 刻 + 夜半鸡鸣这类古称）
- **借位幅度**：往回借 0–4 小时，借 1 小时正好复现上面的效果
- **时光倒流**：最多把表拨慢 4 小时，日期跟着回退
- **秒数抹零**：抹到 5 分或一刻，永远往下抹
- **时间锚点**：真实现在 / 时间膨胀 / 我爱你 / 本小时整点 / 就低不就高 / 永远昨天 / 永远新年

> **就低不就高**：把分钟往下抹到 5 的倍数（秒也一并归零），绝不往前凑 ——
> 22:18 显示 22:15，22:20 才显示 22:20。这个锚点**自带 5 分钟步长**，
> 不需要先去设「秒数抹零」；如果你单独设过抹零，则沿用你设的那个步长。

## 用法

- 右上角 **⚙ 设置** 打开抽屉，按 `Esc` 或点遮罩关闭
- **↺ 回到真实** 一键清掉所有改动
- 设置自动存在你浏览器本地（localStorage），**各人各的，互不影响**

## 一个诚实的说明

默认是「借 1 小时」，所以你打开时看到的表**总是慢一小时** —— 这是功能不是故障，
时间上方的黄色标签会写明当前改动。想看真实时间就点 **↺ 回到真实**。

乙模式的分钟位会超过 59（`18:100` 里的 `100` 不是真的 100 分钟，而是那一格按 100 计），
所以时和分之间用中点 `·` 而不是冒号，避免被读成普通钟点。

这个页面里唯一诚实的部分，是它的名字。
