# 自欺欺人时钟

把时间改成你想看到的样子 —— 包括把 `19:40` 显示成 `18:100`。

**打开即用：** https://yu812812.github.io/time-clock/

单文件网页，纯前端：没有依赖、没有构建、不联网、不收集任何数据。

## 两套进位引擎

| 引擎 | 19:40 显示为 | 说明 |
|---|---|---|
| **乙 · 逐位借位** | `18:100` | 把「1 小时 = 60 分钟」借成「1 小时 = 100 分钟」的读法 |
| **甲 · 规范进位** | `11:800` | 真实分钟按「每 100 记 1」规范化 |

两套都满足：**不重不漏、单调不回头、显示永不晚于真实时间**。

## 我爱你模式

时间锚点里选「**我爱你**」，页面就不再看钟点，而是盯着**每天 5:20**：

```
              07:53 ♥
    上一次 5:20 已过 16 小时 6 分 · 下一次 5:20 还剩 7 小时 53 分
```

- 主显示是**像 24 小时制钟点一样的 `HH:MM`**，表示距离最近的 5:20 还有（或已过）多久
- 中间用粉色 `♥` 代替冒号，一眼看出不是普通钟表
- 下方同时给出**上一次已过多久**和**下一次还剩多久**（两者相加恒为 24 小时）
- 一天有两个 5:20（凌晨和下午），取离现在最近的那个
- 数字跟随「记数文字」设置：选中文就是 `〇七 ♥ 五三`，选文言就是 `〇柒 ♥ 伍參`

## 其它可以调的

- **时段制**：24 小时制 / 12 小时制
- **记数文字**：阿拉伯数字 / 中文小写 / 纯文言（十二时辰 + 刻 + 夜半鸡鸣这类古称）
- **借位幅度**：往回借 0–4 小时，借 1 小时正好复现上面的效果
- **时光倒流**：最多把表拨慢 4 小时，日期跟着回退
- **秒数抹零**：抹到 5 分或一刻，永远往下抹
- **时间锚点**：真实现在 / 时间膨胀 / 我爱你 / 本小时整点 / 就低不就高 / 永远昨天 / 永远新年

## 用法

- 右上角 **⚙ 设置** 打开抽屉，按 `Esc` 或点遮罩关闭
- **↺ 回到真实** 一键清掉所有改动
- 设置自动存在你浏览器本地（localStorage），**各人各的，互不影响**

## 一个诚实的说明

默认是「借 1 小时」，所以你打开时看到的表**总是慢一小时** —— 这是功能不是故障，
时间上方的黄色标签会写明当前改动。想看真实时间就点 **↺ 回到真实**。

乙模式的分钟位会超过 59（`18:100` 里的 `100` 不是真的 100 分钟，而是那一格按 100 计），
所以时和分之间用中点 `·` 而不是冒号，避免被读成普通钟点。

这个页面里唯一诚实的部分，是它的名字。
